# AutoCare Mechanic Booking Prototype

A mobile-friendly static prototype for requesting mechanic bookings.

## Included
- Customer and vehicle details
- Service type and preferred appointment date/time
- Required **“What is your car doing?”** short symptom-description field
- Optional extra notes
- Basic form validation and local browser demo storage

## Run
Open `index.html` in a browser, or enable GitHub Pages for the repository (Settings → Pages → Deploy from a branch → `main` → `/ (root)`).

## Important prototype limitation
This is a front-end demo. Booking requests are stored in the visitor's browser using localStorage; they are not sent to the mechanic and are not shared across devices. A secure backend and mechanic login/dashboard are needed before accepting real customer bookings.
